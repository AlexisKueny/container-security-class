## Linux
- Root user: has all priveleges
- Ordin user: no particular privilege

Problem: no granularity, sometimes you only want some privileges not all.

Linux develops capabilites, allow us to set file or process to set some privileges without having all of them.

## How capabilites work
- pscap: view all processes in host and their capabilites.
- filecap: Display file caps currently set on executable binaries.
